# 基本认识  
## 前言  
目标两个: **维持规律, 不欠睡眠债**  
但, 想要达成目标, 需要的不仅仅是决心.   
其实需要设计安排, 经过我长时间的学习和实践, 首先是因人而异的, 有些人情况比我更好, 执行问题没有我这么多障碍.   
所以我个人收集了不少小巧思, 主要是排除执行困难, 降低执行门槛, 等等, 在此一并分享.   
  
## 基本知识  
关于欠睡眠债怎么办:   
困了就必须想尽办法睡, 既然已经开始关注睡眠问题, 那么就解决它, 而不是抱怨"没条件", "没时间", "没办法".   
  
确定了思想方针, 就下来, 就是怎么做.   
首先, 睡眠, 不只是睡眠的事, 你的起居习惯, 吃穿住行, 光照环境, 等等, 只要稍作设计都能成为你提高睡眠的绝佳助力.   
其次, 不要对睡眠债抱有愧疚感, 你无法入眠, 不想入眠, 都是有原因的, 找到它解决它, 不意味着要bully和审视自己.   
总而言之, 解决睡眠问题, 就只把注意力放在怎么让自己舒服健康的睡觉上, 其他的课题, 等到打开良性的睡眠循环, 自会有更多的精力去处理.

# 科学事实  
## 相关科学  
关键的最初90min睡眠包含了一个非常重要的非REM睡眠区间,  
期间副交感神经活跃, 调节生长激素和免疫的正常运转. 反之, 首个周期如果质量差, 也可能对发育生长, 大脑神经和精神健康产生不好的影响, 如心情不好, 甚至加重抑郁.  抑郁症 与最初90min缩短 之间有很大关系.  
早睡 → 生长激素 → 避免加餐 -> 避免加餐后通宵 -> 从而避免肥胖, 并增强免疫  
一句话总结: 高质量睡眠很重要.   
## 抓住最初的困意  
1. 最初的困意是有产生条件的  
   做自己觉得无聊的事情, 白天积极运动过的身体, 适当强度的体力脑力劳动, 等等.   
2. 最初的困意, 其实同样依赖白天的规律作息, 否则, 你每天都不知道自己几点才会觉得困.  
	这是现在大多数人的现状, 也是失眠的一个重要成因, 因为波动的作息表会撞上波动的可以做也可以不做的事件, 之后越做越兴奋, 导致错过最初的睡意, 然后失眠.   
	  
因此, 需要以下约束:   
```
    - 白天除了午休不要入睡,  因为碎片化的睡眠不能保证频率和时长
    - 想尽一切办法控制精力体力的消耗, 这个后面会提到, 以此确保在适当约定的时间段, 自然产生最初的困意  
    - 11点(个人划线), 困了, 就睡, 强撑过去之后, 很难再有好的深度睡眠  
```  
## 早起  
睡眠以约90min为一个周期, 每个周期内都有一个深度睡眠区间, 身体完全放松, 几乎无法唤醒, 因此, 闹铃需要设置两个, 彼此相隔一定时间. 在睡眠后半段, 深度睡眠区间远没有第一个周期那么长, 这也是强调入睡前准备非常重要的原因, 它直接影响了首个睡眠周期的质量.   
早起的小技巧同样基于此.

## 入睡小技巧  
  
### 制造脑身困意  
9点之后不要运动, 适度活动身体 -> 八段锦  
无聊单调的事情 -> 听舔耳 (但有的人会越听越精神)  
制造小体内体表温度差 -> 热水澡 + 上床后开空调盖厚被子  
别在床上干别的 -> 双层床把手机放在下面充电  
少量饮酒(致癌! 下下选)  
### 舒适的外部环境  
湿度过高不利于排汗,  湿度过低鼻子不适, 温度因人而异 -> 加湿器/除湿器 + 空调  
避免后半夜体温太低 -> 空调开睡眠模式  
暖色光,  滤除蓝光助眠  
睡前90min左右洗完澡或者泡完温泉或足浴,   
制造0.5摄氏度体内升温 (”体温开关”)  
### 打呼噜特攻  
白天要有意识地用鼻子呼吸, 练习腹式呼吸  
选择相对个人而言较矮的枕头,  保证呼吸道顺畅  
### 睡前引导  
播放舒缓, 不引起万千思绪, 又让你开心的歌单 -> 非常值得, 推荐!  
  
单调 -> 引导调整呼吸 -> 让大脑放空 -> 冥想扫视头肩胸腹  
科学数羊 -> 自己搜, 略  
### 其他习惯筛查  
睡前2小时, 不要高强度的脑力体力活动 -> 回想, 复习, 看点闲书, 听听采访就行了  
  
睡前高强度刷手机 -> 只要所有通知都静默了, 你自会养成寻找媒体的本能 ->   
喜欢水群, 刷资讯, 不用戒 -> 直接挑选精选群, 给够固定的时间集中刷, 剩下的扫一眼就好, 平时全部静默通知  
  
到家以后 -> 自动静默大部分社交媒体通知  
## 早起  
间隔约20min的两次铃声,  第一次可以音量小声音短  
起床第一件事, 光脚下地, 洗手洗脸  
新鲜空气 -> 打开窗户, 通风, 非常重要  
唤醒 -> 暖转冷色光, 吃饭细嚼慢咽, 晒太阳, 适量运动  
避免疲惫, 回笼觉的活动 -> 不要久坐, 不要大量出汗  
## 日间保持清醒  
细嚼慢咽  
感触冰凉缓解疲劳  
主动对话积极发言  
扩张手肘下的血管  
黄瓜汁,  冰镇西红柿 (凉性食物和饮品谨慎使用)  
# 其他情况  
## 时差  
核心思路即通过规范化, 把高优先级的排进日程, 避免影响起居 -> 出发前就按照目的地的时间来安排自己的活动, 用餐等  
## 周一忧郁症  
节奏紧凑的会议, 对打破周一忧郁综合征效果很好  
回避那些漫长, 无效, 无效的讨论或者会议 -> 也许作为组员你无法拒绝, 但主动抵消或者避免大部分影响是可以做到的  
## 一天的节奏  
上午: 重要工作  
下午: 模式化工作, 如查阅文献, 简短的会议  
## 不得不熬夜时  
实在是要熬夜, 迎接第一次困意的90min后再起来 (有的人是120min)记得为熬夜做准备, 以及偿还睡眠负债和其他连带影响

| 白天犯困，但又不想把晚上睡意睡没    | 上午后段、下午         | 用短平快的清醒手段过渡，而不是直接乱睡           | 细嚼慢咽、接触冰凉触感、主动对话和发言、起身活动、晒太阳、通风；必要时可用黄瓜汁、冰镇西红柿等偏凉食物/饮品辅助  | 这类方法的目标是“把困意撑到该睡的时候”，而不是把白天也变成第二个睡眠时段  | 凉性食物和饮品谨慎使用，别为了提神把肠胃弄难受                  |  
| 白天活动太少，晚上身体不觉得“该睡了” | 白天 / 晚饭后        | 补一点适度活动，但不要在临睡前把自己搞兴奋         | 白天尽量保持活动量；如果白天过于久坐，可在晚饭后做轻度活动，而不是临睡前高强度运动                 | 困意的一部分来自身体真实的消耗和节律，而不是单靠意志“到点就睡”       | 晚上的活动目标是“助眠”，不是健身冲成绩                     |  
| 周一状态很差，整天像没启动起来     | 周一上午            | 用紧凑、明确、有节奏的任务把自己拉进工作状态        | 把周一上午安排成节奏紧凑的会议或任务块，尽量减少漫长、低效、拉扯人的讨论                      | 周一忧郁很多时候不是“懒”，而是节律断裂后迟迟没进入状态；外部节奏能帮你启动 | 前提是会议/任务本身要有效，不是用低效会议折磨自己                |  
| 有时差，需要尽快切到新时区       | 出发前、旅途中、到达后的前几天 | 提前按目的地时间重排活动、用餐和休息            | 出发前就开始按目的地时间安排高优先级活动和用餐；落地后优先稳住起床和进食时间                    | 时差本质上也是节律重建问题，越早切换，身体越容易适应             | 不要等落地后才开始想“我现在该几点睡”                      |  
| 不得不熬夜，但又不想硬扛一整晚     | 明知当晚必须跨过正常入睡时间时 | 先睡过第一波困意的一个周期，再起来熬            | 在第一次明显困意到来时先睡约90分钟（有的人是120分钟）后再起来；提前准备熬夜期间需要的物资和次日恢复安排    | 比完全硬扛更能保住一部分恢复，也更不容易在后半夜彻底崩掉           | 熬夜后别当没事发生，后续还要考虑补债和恢复                    |  
| 已经欠了睡眠债，白天明显撑不住     | 白天、午后、连续睡不够的阶段  | 把补债设计成可控的白天恢复，而不是彻底放飞作息       | 优先利用固定午休、课间、coffee time 等窗口补一点；一旦困得明显影响功能，就把“先睡一会儿”当成优先事项 | 睡眠债不是靠意志硬扛能解决的，越扛越可能把后面的节律也拖坏          | 补债的重点是“恢复功能 + 尽量不把夜间节律打烂”，不是白天想睡多久睡多久    |
